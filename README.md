# Python Number Guessing Game 🎮

A beginner-friendly Python game where the player tries to guess a randomly generated number within limited attempts based on selected difficulty level.

## Features
- Random number generation
- Difficulty levels (Easy, Medium, Hard)
- Limited attempts system
- High / Low hints
- Score system
- Winning and losing messages
- Beginner-friendly game logic

## Difficulty Levels
| Level | Chances |
|-------|----------|
| Easy | 5 Chances |
| Medium | 3 Chances |
| Hard | 1 Chance |

## Score System ⭐
Players earn points based on remaining chances.

Example:
- Winning early gives higher score
- Winning later gives lower score

## Concepts Used
- Python Basics
- `while` loops
- `if-elif-else`
- User input
- Counters
- Random module
- Game logic

## How to Run

1. Install Python
2. Clone this repository or download the files
3. Open terminal in the project folder
4. Run the program:

```bash
python program.py
````
